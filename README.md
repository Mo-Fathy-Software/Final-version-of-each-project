## ⚙️ Getting Started

Want to explore or run these projects on your machine?

Follow these simple steps.

### 1. Clone the Repository

```bash
git clone https://github.com/MoFathyDevObs/Final-version-of-each-project.git
```

### 2. Navigate to the Project Directory

```bash
cd Final-version-of-each-project
```

### 3. Compile a Project

Make sure you have a C++ compiler such as GCC installed.

For example:

```bash
g++ 01-Stone-Paper-Scissor.cpp -o game
```

### 4. Run the Program

**Windows:**

```bash
game.exe
```

**Linux / macOS:**

```bash
./game
```

Repeat the process with any other `.cpp` file you want to explore.
