### 05. 🏛️ Bank Management System

\<badge>Major Project\</badge>

**File:** `05-BankSystemMoreProfessional.cpp`

A comprehensive console-based Bank Management System developed using **Procedural Programming**.

This is one of the most advanced projects in this repository.

The application provides client management, user management, access control, authentication, and financial transaction operations.

#### ✨ Main Features

**1. Client Management**

- Display all registered clients.
- Add new clients.
- Delete existing clients.
- Update client information.
- Search for clients using account numbers.
- Prevent duplicate account numbers.

**2. User Management**

- Display all registered users.
- Add new users.
- Delete users.
- Update user information.
- Search for users by username.
- Prevent duplicate usernames.

**3. Authentication System**

- Username and password login.
- Login validation.
- Logout functionality.
- Default administrator creation when the users file is empty.

**4. Permissions & Access Control**

- Full administrator access.
- Individual permissions for different operations.
- Permission checking before accessing protected features.
- Bitwise operations for permission management.

**5. Financial Transactions**

- Deposit money.
- Withdraw money.
- Validate transaction amounts.
- Prevent withdrawals exceeding the available balance.
- Display individual client balances.
- Calculate total balances across all clients.

**6. File Management**

- Store client information in `Clients.txt`.
- Store user information in `Users.txt`.
- Load records from text files.
- Add records without overwriting existing data.
- Update and delete records through file rewriting.
- Maintain application data between executions.

#### 🧠 Technical Concepts Applied

| Concept             | Implementation                    |
| ------------------- | --------------------------------- |
| Structures          | Client and User records           |
| Enumerations        | Menus and permission definitions  |
| Vectors             | Managing collections of records   |
| Functions           | Separating application operations |
| File Handling       | Reading and writing text files    |
| String Manipulation | Splitting and formatting records  |
| Bitwise Operations  | Access permissions                |
| Loops & Conditions  | Application logic                 |
| References          | Modifying existing records        |
| Data Processing     | Searching, updating and deleting  |

#### 🏗️ Development Journey

The project was initially built using Procedural Programming.

I'm currently working on redesigning and rebuilding it using **Object-Oriented Programming (OOP)** to improve its architecture, encapsulation, maintainability, and separation of responsibilities.

The goal is to understand how the same application can be designed using two different programming paradigms.

**Current Status:**

- Procedural Version: Implemented.
- OOP Version: In Progress.

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/MoFathyDevObs/Final-version-of-each-project.git
```

### 2. Navigate to the Project

```bash
cd Final-version-of-each-project
```

### 3. Compile a Project

Make sure you have a C++ compiler installed, such as GCC.

```bash
g++ -std=c++17 05-BankSystemMoreProfessional.cpp -o BankSystem
```

### 4. Run the Application

**Windows:**

```bash
BankSystem.exe
```

**Linux / macOS:**

```bash
./BankSystem
```

**Note:** The Bank Management System uses local text files for data storage. It is an educational project, not production banking software. Its current implementation also uses plaintext credentials and a hardcoded default administrator account, so it should not be used with real financial or personal data.
